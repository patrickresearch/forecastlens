# Security Policy

## Supported Versions

ForecastLens is pre-1.0; only the latest released version on PyPI receives fixes.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Instead, report them privately via GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on this repository.

Include a description of the issue, steps to reproduce, and the potential impact. Expect an initial response within a few days.
