    Mean-reverting price process with optional Markov regime switching.

    x_t = x_{t-1} + speed * (target_t - x_{t-1}) + shock_t + jump_t

    target_t combines the active regime's level, a sinusoidal seasonal component, a linear trend, and a one-off structural break. shock_t is Gaussian noise whose variance can cluster via a simple ARCH(1)-style update; jump_t is a rare, larger Gaussian shock.

    def load_preset(name: str) -> GeneratedSeries:
    """Generate a preset series by name."""
    if name not in PRESETS:
        raise ForecastLensError(f"Unknown preset {name!r}. Available: {list_presets()}.")
    return PRESETS[name]()
